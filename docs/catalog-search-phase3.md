# مرحلهٔ سه — فیلترهای پویا و جست‌وجوی ساختاریافته

**وضعیت:** فرانت‌اند و منطق محلی تکمیل شد.  
**محدوده:** فیلترهای پویا، جست‌وجوی دو‌زبانه، نتیجه‌گیری داده‌محور و کنترل عدم نمایش دادهٔ ساختگی.

## اصل اجرایی

فیلتر از «رجیستری ویژگی‌ها» و «قواعد ویژگیِ همان دسته» ساخته می‌شود، نه از فیلدهای ثابت UI. به همین دلیل یک دستهٔ روشنایی در زمان داشتن دادهٔ واقعی می‌تواند توان، لومن، دمای رنگ، IP و نوع نصب را نشان دهد؛ اما همین فیلترها در دسته‌ای که دادهٔ واقعی ندارد نمایش داده نمی‌شوند.

## فایل‌ها

| فایل | نقش |
|---|---|
| `src/lib/catalog/search.ts` | مدل FilterState، نرمال‌سازی فارسی/انگلیسی، جست‌وجو، فیلتر و ساخت Facetها |
| `src/lib/catalog/publishedCatalog.ts` | تنها منبع نتایج عمومی؛ عمداً تا ورود محصول واقعی خالی است |
| `src/components/views/CatalogSearchPanel.tsx` | رابط فیلتر، فیلترهای اصلی، فیلترهای بیشتر و نتیجه‌ها |
| `scripts/verify-catalog-search.ts` | آزمون محلی محصول نمونه، بدون واردکردن آن به کتابخانهٔ عمومی |

## قواعد رابط

- حداکثر شش ویژگی «کلیدی» همان زیر‌دسته در ابتدا نشان داده می‌شود.
- ویژگی‌های «پیشرفته» در «فیلترهای بیشتر» قرار دارند.
- فیلترهای مشترک فقط زمانی دیده می‌شوند که از محصولات منتشرشدهٔ واقعی گزینه‌ای برای آن‌ها وجود داشته باشد:
  - برند؛
  - فرمت فایل؛
  - محتوای قابل‌دسترسی؛
  - وضعیت BIM؛
  - سطح داده؛
  - آخرین به‌روزرسانی.
- هیچ گزینه، تعداد، برند، محصول یا فایل نمونه در `PUBLISHED_CATALOG_PRODUCTS` قرار ندارد.
- تا ورود دادهٔ واقعی، زیر‌دسته فقط Empty State صادقانه و CTA درخواست محصول/برند نشان می‌دهد.

## جست‌وجو

- عنوان، شرح کوتاه، نام برند، کلیدواژه‌ها، نام دسته‌ها و مقدار ویژگی‌های ثبت‌شده جست‌وجو می‌شوند.
- نرمال‌سازی «ی/ي»، «ک/ك»، فاصلهٔ مجازی و رقم فارسی انجام می‌شود.
- چند مترادف رایج فارسی/انگلیسی برای شروع وجود دارد؛ واژگان کامل باید پس از ورود داده و بازخورد واقعی توسعه یابد.

## آزمون

```bash
npx tsx scripts/verify-catalog-search.ts
```

این آزمون یک نسخهٔ داخلی و منتشرنشده از محصول نمونه را بررسی می‌کند و تأیید می‌کند که:

1. جست‌وجوی «پنجره» و `window` نتیجهٔ درست می‌دهد؛
2. فیلتر `frame_material = aluminium` محصول مرتبط را برمی‌گرداند؛
3. مقدار نامرتبط مانند `steel` برنمی‌گردد؛
4. فیلتر عددی ابعاد فقط بازهٔ مرتبط را می‌پذیرد؛
5. Facet فقط از ویژگی دارای داده ساخته می‌شود.
