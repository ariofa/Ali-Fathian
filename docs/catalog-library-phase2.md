# مرحلهٔ دو — کتابخانه و مسیر دسته‌بندی

**وضعیت:** پیاده‌سازی فرانت‌اند تکمیل شد  
**محدوده:** کتابخانهٔ محصول، تاکسونومی دو‌سطحی، URL و Empty State.  
**خارج از محدوده:** فیلترهای تخصصی، جست‌وجوی نتیجهٔ محصول، ثبت درخواست واقعی و بک‌اند.

## مسیرهای پایدار

| مسیر | کاربرد |
|---|---|
| `/library` | صفحهٔ اصلی کتابخانه و ۱۰ خانوادهٔ اصلی |
| `/library/:family` | نمایش زیر‌دسته‌های یک خانواده |
| `/library/:family/:subcategory` | مسیر تخصصی یک خانوادهٔ محصول و Empty State صادقانه تا انتشار دادهٔ واقعی |

نمونه:

```text
/library/doors-windows-openings
/library/doors-windows-openings/windows
```

`/categories` قدیمی به `/library` هدایت می‌شود. هیچ مسیر سوم برای منوی دسته‌بندی ایجاد نشده است.

## تصمیم‌های UX

- صفحهٔ اصلی فقط ۱۰ خانوادهٔ مصوب را نشان می‌دهد؛ تعداد محصول، برند، دانلود یا رتبهٔ ساختگی نمایش نمی‌دهد.
- پس از انتخاب خانواده، فقط زیر‌دسته‌های همان خانواده نمایش داده می‌شوند؛ کاربر با حداکثر دو انتخاب به مسیر تخصصی می‌رسد.
- صفحهٔ زیر‌دسته تا زمان انتشار محصول واقعی، Empty State دارد و ادعا نمی‌کند که محصول یا فایل BIM موجود است.
- CTA مصوب «محصول یا برند موردنظر خود را درخواست کنید» به مسیر درخواست کاربر هدایت می‌شود. اتصال فرم و پیگیری واقعی در مرحلهٔ بعدیِ مربوط به درخواست‌ها/بک‌اند بررسی می‌شود.
- منوی دسته‌بندی Header و پیشنهادهای دسته‌ای جست‌وجو از تاکسونومی جدید `PRODUCT_CATEGORIES` استفاده می‌کنند؛ دادهٔ دسته‌بندی قدیمی کتابخانه دیگر مسیر فعال کاربر نیست.
